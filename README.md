# SkillForge Learning Platform

SkillForge is a Java-based learning management platform developed using Java Swing and object-oriented programming principles. The project simulates a multi-role online learning environment with students, instructors, and administrators interacting through separate dashboards and workflows.

## Features

- User authentication and role-based access
- Student, Instructor, and Admin dashboards
- Course creation and approval workflows
- Quiz creation and management
- Student enrollment and progress tracking
- JSON-based data persistence
- PDF certificate generation using Apache PDFBox
- Analytics and insights visualization using JFreeChart

## Technologies Used

- Java
- Java Swing
- Object-Oriented Programming (OOP)
- JSON
- Apache PDFBox
- JFreeChart
- NetBeans
